# Changelog

## [5.1.0] - 2025-01-29

### Fixed
- Bug critico del backup incrementale (l'archivio includeva se stesso)
- Aggiunta esclusione automatica del file di archivio e delle cartelle di backup

### Added
- Auto-elevazione admin per l'installazione di 7-Zip
- Auto-download e installazione silenziosa di 7-Zip
- Selezione della Root (file sciolti) tramite CheckBox
- Timestamp automatico per i nomi dei backup
- Pulsante ANNULLA per fermare la compressione
- Log su file dettagliato

## [5.0.0] - 2025-01-28

### Added
- Passaggio da WinRAR a 7-Zip (open source)
- GUI Matrix
- Backup singola cartella, sottocartelle e incrementale
